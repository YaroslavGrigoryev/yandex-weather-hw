# Yandex Weather — Java

## Описание проекта

Консольное приложение на Java для получения и обработки метеорологических данных через API Яндекс Погоды.

Приложение отправляет HTTP GET-запрос, получает прогноз в формате JSON и вычисляет среднюю температуру за заданный период.

## Функциональность

- Получение погодных данных через REST API Яндекс Погоды.
- Вывод полного JSON-ответа в консоль.
- Получение текущей температуры (`fact.temp`).
- Расчёт средней температуры по прогнозам (`forecasts[].parts.day.temp_avg`).
- Проверка HTTP-статуса ответа сервера.
- Обработка отсутствующего API-ключа и пустого массива прогнозов.

В текущей реализации используются координаты Москвы (55.75, 37.62) и прогноз на 3 дня (`limit=3`).

## Используемые технологии

- **Java 21** — основной язык программирования.
- **Maven** — управление зависимостями и сборка проекта.
- **Java HttpClient** — отправка HTTP-запросов.
- **Jackson Databind** — обработка JSON-ответов.
- **IntelliJ IDEA** — среда разработки.

## Настройка API-ключа

Для работы приложения необходимо получить API-ключ Яндекс Погоды с доступом к REST API v2.

1. Открыть проект в IntelliJ IDEA.
2. Перейти в **Run → Edit Configurations**.
3. Выбрать конфигурацию запуска `WeatherApp`.
4. Добавить переменную окружения `YANDEX_WEATHER_API_KEY`.
5. Указать полученный API-ключ в качестве значения.
6. Сохранить конфигурацию.

API-ключ не хранится в исходном коде и не должен публиковаться в репозитории.

## Запуск приложения

1. Открыть проект в IntelliJ IDEA.
2. Убедиться, что используется JDK 21.
3. Дождаться загрузки Maven-зависимостей.
4. Настроить переменную окружения с API-ключом.
5. Запустить метод `main()` класса `WeatherApp`.

Для проверки сборки можно выполнить команду `mvn clean package`.

## Результат работы

После успешного запроса приложение выводит в консоль:

- Полный JSON-ответ Яндекс Погоды.
- Текущую температуру в градусах Цельсия.
- Среднюю температуру прогноза за три дня с точностью до двух знаков после запятой.

При ошибке HTTP-запроса или отсутствии необходимых входных данных программа выводит сообщение и прекращает обработку.
